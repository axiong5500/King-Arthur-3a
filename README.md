# 亚瑟 3A 大作

一款基于浏览器的国产 3A FPS 演示作品（WebGL 实时渲染），单机 HTML，双击即可运行。

## 在线试玩

https://axiong5500.github.io/arthur-3a/

## 玩法

- 港区主控已封锁泊位，切断堆场、仓库、码头三处中继
- 空中有机械飞鸥，地面有机械猎犬，三处中继全部断开后前往撤离艇
- 鼠标操作：瞄准 / 射击：左键 / 交互（切断中继）：按住 E / 暂停：Esc

## 运行

直接打开 `index.html`，或起一个静态服务器：

```bash
python -m http.server 8080
```

## 说明

首次加载需要生成贴图与材质，请稍等数秒。
